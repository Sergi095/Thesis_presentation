About this simulation

This playground uses the original DM/ADM model described in this presentation. Prey use DM and respond to nearby predators. Captured prey leave the active swarm.

Each new run uses fresh randomness. Pause preserves the current run; New run draws new initial conditions. Download exports the current state and parameters, not a complete trajectory.

Heading order measures directional agreement (0–1), not whether agents move towards prey. The model includes motion noise and an unbounded arena.
